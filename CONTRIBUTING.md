# Contributing

Open an issue or pull request with an AffineScript-specific resource and a short, original description of who it helps and what they can do with it. Include the canonical link, the last date you checked it, and any version, build, licence, or maintenance caveat. Independent work is welcome; disclose affiliation with a project you add.

We prefer runnable examples, useful documentation, source code, research, and candid critiques. A proposal need not be positive or produced by the language author. We do not equate an open issue, design proposal, or untested example with a working feature. If a link becomes stale but retains historical value, suggest moving it to a labelled historical section.

For code maintenance or a repository transfer, contact the owning project directly. Adding a link here does not transfer stewardship. This collection follows [Stuff of Awe’s maintenance guide](https://github.com/stuff-of-awe/.github/blob/main/docs/collections/MAINTENANCE.adoc); the initial curator is Jonathan D.A. Jewell, and curator succession is welcome.
